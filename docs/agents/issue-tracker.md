# Issue tracker

The originating specification and cross-repository coordination are in
[Orbit-Crew/iDeer #96](https://github.com/Orbit-Crew/iDeer/issues/96), with
[parent #95](https://github.com/Orbit-Crew/iDeer/issues/95).

Desktop code, defects, build and release belong to Orbit-Crew/iDeer-Desktop.
Use GitHub issue URLs when correlating repositories. Read issues and comments
through the GitHub connector, or `gh issue view <number> --repo <owner/repo> --comments`.
Do not post comments or change issue state without authorization.

Protocol authority remains in iDeer. See the
[communication decision](https://github.com/Orbit-Crew/iDeer/issues/34#issuecomment-6161529090).
This bootstrap defines no Server or Runtime protocol and enables no execution.
